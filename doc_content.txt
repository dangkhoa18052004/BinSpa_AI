6. GIAI ĐOẠN 2 — Phân loại loại mụn
Mục tiêu: nhận biết loại tổn thương như blackhead, whitehead, papule, pustule, cyst. GĐ1 trả lời “mụn ở đâu”; GĐ2 trả lời “tổn thương này thuộc loại nào”.
6.1 Dataset và lưu ý
Sử dụng dataset phân loại loại mụn có 5 lớp nếu kiểm tra được nguồn, license và class mapping thực tế. Trước khi dùng, phải kiểm tra số ảnh từng lớp, trùng ảnh, ảnh bị watermark, ảnh crop quá khác so với camera thực tế. Không tự gán “mụn viêm/mụn thường” nếu dataset chỉ có nhãn 5 lớp; mapping nhóm phải được ghi thành rule rõ ràng trong báo cáo.
Ví dụ mapping nghiệp vụ (chỉ dùng nếu bạn chấp nhận rule này trong báo cáo):non_inflammatory = {blackhead, whitehead}inflammatory = {papule, pustule, cyst}Model vẫn train 5 lớp; giao diện có thể gom 5 lớp thành 2 nhóm ở tầng hiển thị.
6.2 Chuẩn bị dataset classification
datasets/phase2_acne_type/├── train/│   ├── blackhead/│   ├── whitehead/│   ├── papule/│   ├── pustule/│   └── cyst/├── val/│   └── ...└── test/    └── ...
Dùng split stratified theo class, ví dụ 70/15/15.
Dùng data augmentation vừa phải: horizontal flip, slight rotation, color jitter nhẹ; tránh augment làm thay đổi màu/texture quá mạnh.
Kiểm tra class imbalance; báo macro-F1 chứ không chỉ accuracy.
Tách ảnh trùng/near-duplicate trước khi split.
6.3 Model đề xuất
Model chính: ConvNeXt-Tiny pretrained ImageNet; baseline: EfficientNet-B0. ConvNeXt là kiến trúc CNN hiện đại, hiệu quả và thuận tiện cho transfer learning. Với RTX 5050 8 GB, input 224 hoặc 288 và batch khoảng 16–32 thường phù hợp, tùy mixed precision và dataset.

7. GIAI ĐOẠN 3 — Phân loại sẹo mụn
Mục tiêu: nhận diện nhóm sẹo mụn/đặc điểm sẹo. Dataset ScarNet được xem như nguồn chuyên biệt nhưng rất nhỏ; vì vậy transfer learning, augmentation và cross-validation là bắt buộc nếu dùng.
7.1 Nhãn mục tiêu
5-class scar:- rolling- icepick- boxcar- hypertrophic- keloidalNhóm hiển thị tùy chọn:Atrophic / sẹo lõm = rolling + icepick + boxcarRaised / sẹo lồi = hypertrophic + keloidal
Không nên tuyên bố model “chẩn đoán sẹo lồi” nếu dataset nhỏ và không có kiểm chứng lâm sàng. Giao diện nên dùng “dấu hiệu giống nhóm…” và confidence.
7.2 Model và cách train
ConvNeXt-Tiny pretrained ImageNet là ứng viên chính.
EfficientNet-B0 làm baseline.
Do dataset nhỏ: 5-fold stratified cross-validation, báo mean ± std macro-F1.
Augmentation vừa phải; có thể dùng class-balanced sampler/loss nếu mất cân bằng.
Sau CV, train final model trên train+val với hyperparameters đã chọn, test trên hold-out nếu dataset đủ; nếu quá nhỏ, minh bạch rằng kết quả là cross-validation.

13. Prompt tổng cho agent để quản lý toàn bộ project
PROMPT CHO AGENT — Agent Orchestrator
Bạn là senior ML engineer phụ trách project Bin Spa Skin AI trên Windows với RTX 5050 Laptop 8GB, Flask + PostgreSQL. Hãy triển khai theo 3 phase, không nhảy phase:PHASE 1: ACNE04 + ACNE04-v2 -> YOLO acne lesion detection.PHASE 2: acne-type dataset 5 lớp -> ConvNeXt-Tiny/EfficientNet-B0 classification.PHASE 3: ScarNet 5 lớp -> ConvNeXt-Tiny/EfficientNet-B0, 5-fold CV.Nguyên tắc bắt buộc:- Luôn audit dataset trước train; không đoán schema/class names.- Không data leakage; dedupe trước split.- Mỗi phase có smoke test, train, eval, error analysis và model artifact versioned.- Không dùng test set để chọn hyperparameter.- Ưu tiên chạy được trên 8GB VRAM; dùng AMP và giảm batch khi OOM.- Không tự động tiếp tục phase kế nếu acceptance criteria phase hiện tại chưa đạt; hãy báo blocker.- Tạo README và lệnh reproducible cho mọi script.- Kết quả da chỉ mang tính phân tích hình ảnh/tham khảo chăm sóc; không chẩn đoán bệnh.- Cuối mỗi phase cập nhật reports/phaseN_summary.md với dataset version, split, config, metrics, failure cases và đường dẫn model.Trước khi viết code, hãy in kế hoạch file sẽ tạo và những giả định cần xác minh. Chỉ sau đó mới triển khai.
